# M0.5 Trace Context Qualification Patch

Status: **COMPLETED**  
Patch line: **v0.9.1**

## Scope

This patch deliberately addresses one M0.5 qualification point only: preserving call context across nested capability invocations and stream control.

## Changes

1. `RequestContext.Query` / `RequestContext.Command` child envelopes preserve the incoming `trace_id` and `correlation_id`.
2. Child `causation_id` is the immediate parent request `message_id`.
3. Child deadlines are capped by the parent deadline.
4. The SDK's local wait timeout is now also capped by the envelope deadline; it cannot wait beyond the inherited deadline.
5. `stream.data`, `stream.close`, and consumer `cancel` envelopes carry trace/correlation/causation context.
6. Root invocations still create a fresh trace/correlation pair.

## Regression tests added

`/sdk/go/pluginhost/host_test.go` verifies:

- trace inheritance;
- correlation inheritance;
- immediate causation;
- parent deadline dominance;
- expired deadline rejection;
- stream cancellation context propagation;
- fresh context for root calls.
